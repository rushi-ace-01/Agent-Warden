IMPORTANT: The admission webhook needs a TLS cert and the
ValidatingWebhookConfiguration's caBundle patched. Run:

  scripts/gen-webhook-certs.py --service admission-webhook \
    --namespace {{ .Values.namespace.name }} --out-dir tls > tls/ca.b64
  kubectl -n {{ .Values.namespace.name }} create secret tls admission-webhook-tls \
    --cert=tls/tls.crt --key=tls/tls.key --dry-run=client -o yaml | kubectl apply -f -
  kubectl patch validatingwebhookconfiguration agent-warden \
    --type=json -p="[{\"op\":\"replace\",\"path\":\"/webhooks/0/clientConfig/caBundle\",\"value\":\"$(cat tls/ca.b64)\"}]"

In production, use cert-manager instead.
